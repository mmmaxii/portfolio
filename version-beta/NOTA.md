# Versión beta del portafolio

Esta carpeta guarda la versión anterior del portafolio (mapa estelar dibujado con CSS y canvas), tal como estaba antes del rediseño con el cielo real.

No se compila con el sitio actual (está excluida en `tsconfig.json` y `eslint.config.mjs`). Para volver a usarla, mueve `app`, `components`, `data` y `lib` de esta carpeta a la raíz del proyecto, en lugar de los actuales.
